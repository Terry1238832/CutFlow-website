READY WHEN YOU ARE.

设置一次，从此顺手。

三个步骤，让 CutFlow 准备就绪。

  1. 01

    拖入应用程序

    下载并解压安装包，将 CutFlow.app 拖入 Mac 的“应用程序”文件夹。

  2. 02

    批准首次打开

    当前版本未经 Apple 公证。若系统阻止打开，核对来源后，在“隐私与安全性”中点击“仍要打开”。

  3. 03

    开启辅助功能

    在系统设置中授予 CutFlow 辅助功能权限。回到应用点击“重新检测”，然后用测试文件试试 ⌘X 与 ⌘V。

辅助功能权限用于识别并转换快捷键。授权由你在 macOS 系统设置中完成。

GOOD TO KNOW.

下载之前，
你可能想知道。

把能力与边界，都说清楚。

支持哪些 Mac？+

提供 Apple Silicon 与 Intel 通用安装包，编译目标为 macOS 13 或更新版本。Intel 真机、旧版 macOS 及跨磁盘场景尚未完成全面实测。建议先用临时文件确认你的使用环境。

剪切后，文件会立刻消失吗？+

不会。⌘X 会复制文件信息并记录待移动状态，原文件仍在原处；在同一文件管理器中按 ⌘V 后，才调用原生移动。按 Esc 可以取消剪切，剪贴板仍保留，可用于普通复制。

已经授权，却还提示没有权限？+

旧签名或另一份同名应用可能导致授权不匹配。先核对 CutFlow 中显示的当前应用路径，退出旧版本，再在系统辅助功能列表中移除旧记录、添加正在使用的应用，最后重新检测。系统要求身份验证时，由你本人完成。

可以像 Windows 一样让图标变淡吗？+

提供可关闭的实验淡化功能，通过覆盖层模拟，并不修改 Finder 图标的真实透明度。当前仅针对 Finder 窗口的图标视图；列表、分栏、画廊、桌面及 ForkLift 不显示。完整视觉效果仍未完成验收，因此新安装默认关闭。

普通复制、文字编辑还正常吗？+

没有有效剪切标记时，⌘V 保持普通粘贴。默认开启文字编辑保护，识别到搜索、重命名等输入控件时，保留原有快捷键。不要与 Command X 或同类快捷键工具同时启用。

这个版本经过了哪些测试？+

Debug 与 Release 各通过 58 项自动化测试；Finder 原生多文件移动、普通撤销、冲突停止及“保留两者”经过文件哈希验证。1.1.3 真实键盘全局监听的完整回归、实验淡化视觉效果、ForkLift 和登录启动等仍待验证。“保留两者”后的撤销未确认通过。查看完整测试报告 ↗
